# Proyecto Biblioteca

Base de datos de una biblioteca con 10 libros y sus autores.

## Archivos
- Biblioteca.sql - Base de datos exportada desde DB Browser
- Biblioteca.db - Base de datos SQLite
- Biblioteca.R - Codigo en R para consultar la base

## Tablas
- Autores: Id_autor, nombre, pais
- Libros: Id_libros, titulo, año, Id_autor

## Como usarlo
1. Abrir Biblioteca.db en DB Browser
2. Abrir Biblioteca.R en RStudio y darle Run
3. Se muestran los 10 libros con su autor
